# ФРЕЯ — сайт партнёра Davines

Многостраничный сайт студии «Фрея» и Кристины — амбассадора Davines. Витрина с каталогом
продукции, многошаговый подбор ухода, запись на приём и заказ продуктов.

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · статические JSON-данные

**Сайт:** https://andrewf250.github.io/Freya/

---

## Быстрый старт

```bash
npm install
cp .env.example .env
npm run dev
```

Сайт — http://localhost:3000

## Редактирование контента

Сайт собирается из статических JSON-файлов:

- `src/data/products.json` — каталог товаров (цены, описания, видимость, избранное)
- `src/data/settings.json` — контакты, тексты на главной и в разделах

После изменений закоммитьте и запушьте в `main` — GitHub Actions автоматически обновит сайт.

Кабинет `/master` работает в браузере через localStorage (без сервера) — удобен для быстрых правок.
Для постоянных изменений надёжнее редактировать JSON и пушить в репозиторий.

Чтобы пересобрать JSON из локальной базы Prisma (если она есть):

```bash
npm run export-data
```

## Формы заказа и записи

Заявки отправляются через [Web3Forms](https://web3forms.com/) на e-mail.

1. Зарегистрируйтесь на web3forms.com и получите access key.
2. Для локальной разработки — вставьте ключ в `.env` как `NEXT_PUBLIC_WEB3FORMS_KEY`.
3. Для GitHub Pages — добавьте secret `WEB3FORMS_KEY` в настройках репозитория на GitHub.

## Деплой на GitHub Pages

Сайт публикуется автоматически при пуше в ветку `main` через GitHub Actions.

1. В настройках репозитория: **Pages → Source: GitHub Actions**
2. Добавьте secret `WEB3FORMS_KEY` для работы форм
3. URL: `https://andrewf250.github.io/Freya/`
